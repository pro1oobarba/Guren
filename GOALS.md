# Цели проекта

## Зачем это вообще

Один AI-движок (`AI.generate()`), который засовываешь в любой свой проект
(бот, DM-ассистент, анализатор чего угодно) и он просто работает — сам
выбирает живую бесплатную модель под задачу, сам переключается при отказе,
сам помнит контекст. Цель — не построить самую умную систему на свете, а
построить **надёжный бесплатный слой по умолчанию**, который не надо
перенастраивать под каждый новый проект.

## Не цели (осознанно)

- **Не замена платному фронтиру.** Честная оценка (см. CHANGELOG /
  обсуждение в сессии) — DeepSeek-V3/GPT-OSS-120B на free tier примерно
  на уровне GPT-4o-mini/Claude Haiku для простых-средних задач. Для
  сложного многошагового рассуждения и агентности это не замена Claude
  Opus/Sonnet, GPT-5, Gemini 3 Pro — другая весовая категория. Ядро — это
  бесплатный fallback-слой, не попытка догнать frontier.
- **Не автобенчмаркинг моделей.** Каталоги бесплатных моделей меняются
  каждую неделю — курируемая вручную tier-таблица (`router/modelTiers.js`)
  сознательно выбрана вместо погони за идеальной авто-оценкой качества,
  которая устареет быстрее, чем окупится.
- **Не многопользовательский сервис.** Пока рассчитан на один процесс,
  одного владельца ключей. Не проектируем под конкурентный доступ
  нескольких независимых пользователей, пока не появится реальная нужда.

## Принципы, которые не нарушать при дальнейшей разработке

1. **Zero dependencies.** Только встроенные модули Node.js + нативный
   `fetch`. Ни один пункт бэклога не должен тянуть npm-пакет, если
   задачу можно решить встроенными средствами.
2. **Один новый провайдер = один новый файл.** Не трогать
   Router/HealthChecker/kernel.js структурно ради добавления провайдера.
3. **Деградация, а не падение.** Отказ одного провайдера/модели никогда
   не должен ронять `AI.generate()`, пока жив хотя бы один кандидат.
4. **Ключи и секреты не покидают `.env`.** Ни в коде, ни в логах, ни в
   git-истории. Раз проект идёт в приватный GitHub — это не декларация,
   а требование, которое надо проверять перед каждым пушем.
5. **Drop-in first.** Любое архитектурное решение оценивать вопросом:
   «упростит или усложнит это встраивание ядра в новый проект без
   переписывания самого ядра?»

## Текущий статус (обновляется)

- 9 провайдеров в коде, 6 активны и бесплатны (Groq, OpenRouter,
  Cloudflare, Cerebras, SambaNova, HuggingFace), Gemini активен с
  ограниченной дневной квотой, DeepInfra/Hyperbolic выключены (баланс $0).
- Роутинг — tier-таблица + auto-fallback + auto-cooldown/retry.
- Память — персистентная (JSON), переживает рестарт процесса.
- Git-репозиторий инициализирован, секреты в `.gitignore`, публикация в
  приватный GitHub — запланирована, не выполнена.
